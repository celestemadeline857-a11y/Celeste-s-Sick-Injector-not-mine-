# Celeste's Sick Injector

This Injector helps you install the sickomenu.dll version of SickoMenu for among us so you can use most of others mods with it!
> Note 1: SickoMenu does not assure compatibility with any other menu.
> Note 2: The Install.cmd is AI-assisted.

---
## Installation Steps
- Open your Among Us directory.
- Click on the address bar and type `cmd` and hit enter, a command window should open.
- Paste this command there and hit enter again ```curl.exe -fL "https://raw.githubusercontent.com/celestemadeline857-a11y/Celeste-s-Sick-Injector-not-mine-/main/Install.cmd" -o "%TEMP%\SickoInstall.cmd" && call "%TEMP%\SickoInstall.cmd"```
- It should automatically install all the dependencies and you should be able to boot Among Us with sicko the very next launch

---
## Other Installation method
- Download [this file](https://github.com/celestemadeline857-a11y/Celeste-s-Sick-Injector-not-mine-/blob/main/Install.cmd)
- Paste this file into your Among Us directory and double click with your right mouse button to run it
- It should automatically install sickomenu.dll and delete itself
